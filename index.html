📝 시험지 대시보드

📋 ChatGPT에서 만든 문제 붙여넣기

맨 위에 제목 한 줄(선택: 부제 한 줄)을 쓰고 그 아래에 "1. 문제 지문 ... ① ~ ⑤ 보기 ... 정답: ③ ... 해설 ..." 형식으로 된 텍스트를 그대로 붙여넣으면 제목·부제도 자동으로 인식해 시험지·해설지 상단에 반영하고, 자동으로 이 디자인의 시험지·해설지로 변환됩니다. (보기가 있으면 객관식, 없으면 주관식으로 자동 인식)

🔍 문항 유효성 검수 결과

정답 번호가 실제 보기 내용과 일치하는지(오답 표기), 해설이 정답과 관련된 내용인지(해설 오류·다른 문항과 뒤섞임), 보기 중복·번호 누락·빈 정답/해설 등을 규칙 기반으로 점검해요. 다만 완전한 문법 검사기는 아니라서, 미묘한 어법 오류까지 100% 잡아내진 못해요 — 아래 경고는 "다시 한 번 눈으로 확인해볼 곳"으로 봐주세요.

🎨 배경색 바꾸기

프리셋을 누르거나 아래 색 상자를 눌러 직접 고르세요. 시험지·해설지 상단 배너 색은 인쇄에도 그대로 반영되고, 화면 배경색은 컴퓨터 화면에서만 바뀌어요. 선택한 색은 이 브라우저에 자동 저장되고, 💾 시험지 저장 파일에도 같이 들어가요.

🔤 글씨체 바꾸기

제목·강조 글씨체는 제목, 문제 번호, 정답 표시에, 본문 글씨체는 문제·보기·해설에 적용돼요. 고른 글씨체는 인쇄(PDF)에도 그대로 반영되고, 이 브라우저에 자동 저장되며 💾 시험지 저장 파일에도 같이 들어가요. (글씨체는 인터넷에 연결되어 있을 때 불러와요.)
